# Java

## 기초
- 데이터 타입, 연산자
- 컬렉션 프레임워크
- 예외 처리
- 제네릭, 람다, 스트림

## OOP
- 캡슐화, 상속, 다형성, 추상화
- SOLID 원칙
- 인터페이스 vs 추상 클래스

## JVM
- JVM 구조 (ClassLoader, Runtime Data Area, Execution Engine)
- 가비지 컬렉션 (GC 알고리즘, 튜닝)
- 메모리 구조 (Heap, Stack, Metaspace)

## Concurrency
- Thread, Runnable, Callable
- synchronized, volatile
- java.util.concurrent (ExecutorService, CompletableFuture)
- 동시성 이슈 & 해결

## Modern Java
- Java 11+ 주요 기능
- Record, Sealed Class
- Virtual Thread (Java 21)
- Pattern Matching
