# 데이터베이스

## RDBMS 기초
- 정규화 (1NF ~ 3NF, BCNF)
- 트랜잭션 (ACID)
- 격리 수준 (Read Uncommitted ~ Serializable)
- 인덱스 (B-Tree, Hash, Covering Index)
- 실행 계획 (EXPLAIN)

## MySQL
- InnoDB 아키텍처
- 락 (Record Lock, Gap Lock, Next-Key Lock)
- 리플리케이션
- 쿼리 최적화

## JPA & Hibernate
- 영속성 컨텍스트
- 엔티티 매핑, 연관관계 매핑
- 지연 로딩 vs 즉시 로딩
- JPQL, QueryDSL

## Redis
- 자료구조 (String, List, Set, Hash, Sorted Set)
- 캐시 전략 (Cache Aside, Write Through)
- TTL, Eviction Policy
- Pub/Sub
- Redis Cluster, Sentinel
